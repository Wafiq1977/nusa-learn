Penjelasan Aktor

AktorDeskripsi
🧒 Siswa SDPemain utama (kelas 1-6). Berinteraksi dengan semua fitur game, mini-games, multiplayer, dan tracking.
👨‍🏫 Admin / Guru / Orang TuaMengelola konten (CRUD soal) dan monitoring perkembangan siswa via dashboard. Login dengan password.
🤖 Sistem AI (NOVA)Robot pendamping yang memberikan hint adaptif (LLM-powered), mengatur tingkat kesulitan, dan feedback positif.

Hubungan Include / Extend

  • Mainkan Level includes → salah satu dari 9 mini-games (Choice, Story, Pattern, Build, Catch, Shop, Path, Battle, Team Battle)
  • Mainkan Level extends → Minta Petunjuk (siswa bisa minta hint saat bingung)
  • Setup Tim includes → Mode Bergiliran atau Mode Siapa Cepat
  • Kedua mode multiplayer includes → Timer Menjawab

Struktur database NUSA LEARN — 4 entitas utama: Player, Question, Badge, SessionLog.

Penjelasan Entitas

EntitasAtribut KunciDeskripsi
🧑 PLAYER id (PK), name, grade, xp, coins, stars, badges, characterJson, settingsJson Data pemain lokal. Berisi identitas, currency, progress, kustomisasi karakter, dan settings. Persist di localStorage (client-side) untuk privacy siswa SD.
📝 QUESTION id (PK), grade, category, subcategory, difficulty, gameType, question, options, answer, hints Bank soal — 574 soal (454 numerik + 120 literasi). Bisa dikelola admin via CRUD. gameType menentukan mini-game yang dipakai.
🏆 BADGE id (PK), name, description, icon, category, requirement Definisi achievement (12 badge). Mis. "Math Explorer", "Reading Explorer", "Daily Hero", dll.
📋 SESSION_LOG id (PK), playerName, area, level, correct, wrong, xpGained, duration Log sesi belajar untuk analytics admin. Tiap sesi selesai = 1 row baru.

Relasi

DariKeTipeDeskripsi
PLAYERSESSION_LOG1:NSatu pemain bisa punya banyak sesi belajar
PLAYERBADGEM:NPemain dapat banyak badge (via JSON badges array di PLAYER)
QUESTIONSESSION_LOGM:NSoal direferensikan via level/area (tidak FK langsung)

💡 Catatan: Relasi PLAYER-BADGE tidak pakai junction table — disimpan sebagai JSON array di field badges di PLAYER. Ini karena SQLite/PostgreSQL bisa simpan JSON. Untuk query badge pemain, parse JSON di aplikasi.
